# SSN-688 — public builds

Downloadable **compiled builds** of [SSN-688 Modern Submarine Combat Simulator](https://github.com/bubnov-mikhail/ssn688).

The game **source code is private**. This repository exists only so anyone can grab release binaries without access to the development repo.

## Downloads

Open **[Releases](https://github.com/bubnov-mikhail/ssn688-releases/releases)** and pick the asset for your platform:

| Asset | Platform |
|-------|----------|
| `ssn688-*-macos-arm64.zip` | macOS Apple Silicon (`.app` inside the zip) |
| `ssn688-*-linux-amd64` | Linux x86_64 |
| `ssn688-*-windows-amd64.exe` | Windows 64-bit |
| `ssn688-*-windows-386.exe` | Windows 32-bit |
| `ssn688-*-android-debug.apk` | Android (debug APK) |
| `ssn688-*-manual-en.pdf` | Player manual (English) |
| `ssn688-*-manual-ru.pdf` | Player manual (Russian) |

Ignore the auto-generated **Source code (zip/tar.gz)** links on each release — they only contain this README, not the game.

## Notes

- Builds are produced by CI from the private development repository.
- Debug/dev tooling is stripped in release tags (`ssnrelease`).
- Questions / feedback: open an issue here or contact the author via GitHub.
