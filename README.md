# SSN-688 — public builds

Downloadable **compiled builds** of **SSN-688 Modern Submarine Combat Simulator**.

**Site:** https://bubnov-mikhail.github.io/ssn688-releases/

The game **source code is private**. This repository exists so anyone can grab release binaries (and the GitHub Pages landing) without access to the development repo.

## Downloads

Prefer the [landing page](https://bubnov-mikhail.github.io/ssn688-releases/) or open **[Releases](https://github.com/bubnov-mikhail/ssn688-releases/releases)** / [latest](https://github.com/bubnov-mikhail/ssn688-releases/releases/latest).

| Asset | Platform |
|-------|----------|
| `ssn688-windows-amd64.exe` / `ssn688-*-windows-amd64.exe` | Windows 64-bit |
| `ssn688-windows-386.exe` / `ssn688-*-windows-386.exe` | Windows 32-bit |
| `ssn688-macos-arm64.zip` / `ssn688-*-macos-arm64.zip` | macOS Apple Silicon (`.app` in the zip) |
| `ssn688-linux-amd64` / `ssn688-*-linux-amd64` | Linux x86_64 |
| `ssn688-android.apk` / `ssn688-*-android.apk` | Android |
| `ssn688-manual-en.pdf` / `ssn688-*-manual-en.pdf` | Player manual (English) |
| `ssn688-manual-ru.pdf` / `ssn688-*-manual-ru.pdf` | Player manual (Russian) |

Stable names (without the version) always track the newest release via `/releases/latest/download/…`.

Ignore the auto-generated **Source code (zip/tar.gz)** links on each release — they only contain this README, not the game.
